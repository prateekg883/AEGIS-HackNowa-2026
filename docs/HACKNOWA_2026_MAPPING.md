### Why Problem Statement 3?
Modern society's security is deeply rooted in digital systems—power distribution, banking ledgers, hospitals, telecommunications, and defense grids. When a Security Operations Center (SOC) fails to detect a breach or prematurely closes a malware ticket without verification, millions of citizens are placed at risk. **A.E.G.I.S.** directly tackles this challenge by providing an autonomous, deterministic supervisory AI engine that uncovers what the SOC missed or suppressed.

## 🏆 Scoring Across HackNowa's 5 Evaluation Criteria

### 1. Innovation & Originality (Top Tier)
* **Negative-Space Reasoning**: Traditional SIEMs (Splunk, ArcSight, QRadar) only process received logs. A.E.G.I.S. models the *absence* of expected telemetry (unmonitored network segments, missing DNS flows during malware triggers, off-hours sensor silences).
* **Deterministic AI vs. Generative Hallucinations**: Standard LLMs hallucinate explanations and cannot be cited in legal or regulatory cyber audits. A.E.G.I.S. uses deterministic mathematical scoring and cryptographic audit trails.
* **Privacy-Preserving Sectoral Radar**: Enables national watchdogs to benchmark peer entities without leaking sensitive internal security topologies.

### 2. AI / Technical Implementation (Comprehensive Applied AI)
* **Applied AI Anomaly Detection**: Uses NumPy and SciPy statistical modules to derive z-score distributions, MTTR/MTTC variance, and cohort percentile rankings.
* **Universal Normalization Engine**: Ingests and maps 8 log formats (CEF, LEEF, Syslog RFC-5424, Windows XML, Parquet, JSON, XLSX) into unified Elastic Common Schema (ECS).
* **Cryptographic Provenance**: Every finding is linked to immutable raw event records and stored in a sequential SHA-256 chained audit ledger.
* **Modern Stack**: Python 3.12+ FastAPI asynchronous REST API + React 19 / Vite frontend + Three.js 3D enclave globe visualization.

### 3. Problem Relevance & Impact (Strategic Value)
* **Critical Sector Entity (CSE) Defense**: Designed specifically for energy, banking, telecom, defense, and healthcare.
* **Regulatory Compliance**: Built to fulfill supervisory requirements like CERT-In directives, NCIIPC guidelines, NIST SP 800-61r2 incident response playbooks, and the DPDP Act 2023.
* **Operational Efficiency**: Reduces supervisory audit cycles from weeks of manual spreadsheet inspection to automated, instantaneous reports.

### 4. Functionality (100% Operational)
* **10 Working Core Views**: Executive Decision Room, Multi-CSE Radar Comparator, Negative Space Analytics, Evidence Explorer, Playbook Audit, Outbound Cryptographic Gateway, Air-Gap Telemetry, Ingestion Batch Manager, Assessment Reports, and System Settings.
* **Zero Cloud Leakage**: Air-gapped enclave operation using local SQLite or PostgreSQL.
* **Automated Verification**: Complete 30-point automated test suite (`verify_aegis_system.py`) verifying database integrity, scoring bounds, RBAC permissions, and cryptographic signatures.

### 5. Presentation & Demo (High Production Value)
* **Visual Excellence**: Dark-mode cyber aesthetic (`#060d1f`), Orbitron and JetBrains Mono typography, interactive radar charts, glassmorphism cards, and zero layout shift.
* **Ready-to-Record Pitch Script**: 4-minute timed video script in `docs/demo_pitch_script.md`.
* **One-Click Launch**: Double-click `START_PROJECT.bat` to launch backend and frontend simultaneously.
