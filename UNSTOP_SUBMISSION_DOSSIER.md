## 📝 1. Executive Summary (For Unstop "Project Description" Box)

Modern society is completely dependent on digital critical infrastructure—smart electrical grids, central banking clearinghouses, telecommunications networks, healthcare systems, and defense corridors. While individual entities run internal Security Operations Centers (SOCs) with diverse SIEM tools (ArcSight, QRadar, Splunk, Elastic), national regulators (e.g., CERT-In, NCIIPC, RBI, NIST) and enterprise CISOs face an asymmetric governance crisis: they have no automated way to verify **what the SOC missed, failed to log, or prematurely closed**.

**A.E.G.I.S.** (Analytics & Evidence-based Governance Intelligence System) solves this challenge by introducing an **offline-first, evidence-grounded supervisory AI engine**. Moving beyond hallucination-prone GenAI and passive alert viewers, A.E.G.I.S. normalizes 8+ heterogeneous log formats into Elastic Common Schema (ECS), performs **negative-space reasoning** to detect unmonitored attack vectors and dropped telemetry, audits incident triage against NIST playbooks to catch execution gaps, and computes bounded composite **Attention Scores (0–100)** with z-score anomaly distributions. With zero cloud data leaks, sequential SHA-256 cryptographic audit chaining, and an HMAC-SHA256 critical escalation gateway, A.E.G.I.S. delivers mathematically defensible digital safety for critical infrastructure.

> *"Develop an innovative solution that protects people, businesses, or digital systems from modern cyber threats."*

### Why A.E.G.I.S. is the Definitive Solution:
1. **Protection of Digital Systems & People**: A breach in a power grid or bank affects millions of ordinary citizens. A.E.G.I.S. provides the supervisory oversight that prevents silent, catastrophic cyber disruptions across Critical Sector Entities (CSEs).
2. **Defeating Modern Advanced Persistent Threats (APTs)**: Modern state-sponsored cyber attackers deliberately disable logging sensors, spoof timestamps, and rely on SOC fatigue to hide. A.E.G.I.S.'s **Negative-Space Discovery Engine** mathematically flags telemetry voids and silent periods that attackers rely upon.
3. **Preventing Premature Incident Closures**: Attackers often trigger low-priority alerts to test defenses. A.E.G.I.S.'s **Execution Gap Engine** automatically flags alerts closed in under 5 minutes without mandatory escalation, digital forensic capture, or secondary analyst review.
4. **Guaranteed Sovereign Privacy (Air-Gapped AI)**: Conventional AI tools stream confidential enterprise security logs to third-party cloud APIs, creating massive data leakage risks. A.E.G.I.S. runs 100% on-premises with zero external network dependencies.

## 🏆 3. HackNowa Evaluation Criteria Alignment

A.E.G.I.S. has been meticulously engineered to score top marks across all five official HackNowa evaluation pillars:

### 1. Innovation & Originality
- **Negative-Space Reasoning**: Unlike traditional SIEMs that only inspect what is logged, A.E.G.I.S. calculates what is *missing* (e.g., absent DNS flow telemetry during malware alerts, missing endpoint telemetry during off-hours).
- **Deterministic AI vs. Stochastic LLMs**: Forensic investigations and regulatory audits require legal certainty. A.E.G.I.S. replaces non-reproducible generative LLMs with deterministic mathematical scoring and rule-linked provenance graphs.
- **Privacy-Preserving Peer Benchmarking Radar**: Cross-entity sectoral benchmarking without sharing confidential raw security telemetry between competing organizations.

### 2. AI / Technical Implementation
- **Applied AI & Statistical Anomaly Engine**: Employs NumPy and SciPy statistical modules to derive z-score distributions, mean-time-to-containment (MTTC) variances, and cohort deviation matrices.
- **Universal SIEM Normalization Engine**: Built-in parsers for CEF (ArcSight), LEEF (QRadar), Syslog RFC-5424, Windows XML, Apache Parquet, JSON, and XLSX into Elastic Common Schema (ECS).
- **Cryptographic Provenance Ledger**: Every supervisory finding is tied to raw event hashes and recorded in a sequential SHA-256 cryptographic hash chain, guaranteeing non-repudiation.
- **Enterprise-Grade Stack**: Python 3.12+ / FastAPI asynchronous backend with SQLAlchemy ORM, paired with a React 19 + Vite frontend featuring real-time interactive Three.js 3D enclave globe and Recharts data visualizations.

### 3. Problem Relevance & Impact
- **National & Enterprise Strategic Defense**: Directly safeguards critical infrastructure (Energy/PowerGrid, Banking/SBI, Telecom/Airtel, Health, Defense) from ransomware and APTs.
- **Solving SOC Burnout & Compliance Blindspots**: Eliminates the manual audit of millions of logs, cutting supervisory assessment turnaround from weeks to seconds.
- **Strict Compliance Alignment**: Pre-mapped to NIST SP 800-61r2 incident response playbooks, CERT-In compliance directives, and the Digital Personal Data Protection (DPDP) Act 2023.

### 4. Functionality
- **Fully Working End-to-End System**: Not a conceptual prototype or UI mockup. The complete system includes:
  - **Executive Decision Room**: Live cohort attention scores, priority triage, and drilldowns.
  - **Multi-CSE Radar Comparator**: Multi-dimensional sector benchmarking.
  - **Negative Space Analytics Console**: Telemetry coverage matrices and silence detection.
  - **Universal Evidence Ingestion & Explorer**: Multi-format log drag-and-drop parser.
  - **Incident & Finding Workspace**: Triage playbooks, verification checklists, and audit notes.
  - **Air-Gap Telemetry & Cryptographic Audit Ledger**: Immutable verification logs and zero-cloud posture indicators.
  - **Secure Outbound Gateway**: Gatekeeper restricting outbound transmission to Score ≥ 98 with HMAC-SHA256 signing and 14-field data minimization.
- **30-Point Automated Verification Suite**: Verified by `verify_aegis_system.py` passing 100% of functional and security tests.

### 5. Presentation & Demo
- **Polished Cyber-Supervisory UI**: Sleek dark mode palette (`#060d1f` cyber aesthetic), Orbitron & JetBrains Mono typography, smooth glassmorphism, responsive micro-animations, and zero layout shift.
- **Dedicated Pitch Script & Walkthroughs**: Complete scripts provided in `docs/demo_pitch_script.md` and `docs/DEMO_EXPLANATION_SCRIPT.md` tailored for jury evaluations.

## ⚡ 5. Quickstart & Evaluation Guide (For HackNowa Judges)

### Option A: One-Click Instant Launch (Windows - Recommended)
1. Extract the submission ZIP file: `AEGIS_HackNowa_Global_Hackathon_2026_Submission.zip`
2. Open the extracted folder.
3. Double-click **`START_PROJECT.bat`**.
4. The automated script will:
   - Configure Python virtual environment & install requirements.
   - Run database migrations & seed comprehensive demonstration data.
   - Start the FastAPI backend on `http://127.0.0.1:8000`.
   - Start the React frontend on `http://localhost:3000`.
   - Automatically launch your browser directly to the A.E.G.I.S. Executive Decision Room.

To stop the system cleanly: Double-click **`STOP_PROJECT.bat`**.

---

### Option B: Manual Terminal Launch

**Step 1: Start Backend**
```powershell
# Open Terminal 1
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1   # (On Linux/macOS: source .venv/bin/activate)
pip install -r requirements.txt
alembic upgrade head
python -m app.db.seed_demo
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

**Step 2: Start Frontend**
```powershell
# Open Terminal 2 (Workspace root)
npm install
npm run dev
```
Open your browser at `http://localhost:3000`.

### Option C: Automated System Verification Test
Run the comprehensive 30-point test suite to verify analytical accuracy, cryptographic hashes, and role-based access control:
